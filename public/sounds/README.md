# Poker Game - Sound Assets

This directory contains audio files for the poker game.

## Directory Structure

- **game/** - Game-related sounds (cards, chips, victory)
- **ui/** - User interface sounds (buttons, notifications)

## Required Sound Files

### Game Sounds (public/sounds/game/)
- `card-shuffle.mp3` - Card shuffling sound
- `card-deal.mp3` - Card dealing sound  
- `chip-bet.mp3` - Chip betting sound
- `chip-win.mp3` - Winning pot sound
- `victory.mp3` - Tournament victory sound
- `fold.mp3` - Fold action sound

### UI Sounds (public/sounds/ui/)
- `button-click.mp3` - Button click sound
- `button-hover.mp3` - Button hover sound
- `error.mp3` - Error/invalid action sound
- `notification.mp3` - Notification/alert sound

## Adding Sounds

1. Find or create sound files (MP3 format recommended)
2. Place them in the appropriate directory
3. Keep file sizes small (<100KB per sound)
4. Ensure filenames match exactly as listed above

## Free Sound Resources

- **Freesound.org** - Creative Commons sounds
- **Zapsplat.com** - Free game sounds  
- **Mixkit.co** - Free sound effects
- **SFXR/Bfxr** - Generate retro game sounds
