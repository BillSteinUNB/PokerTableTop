# Placeholder Sound Files

This directory contains placeholder silent audio files.

**IMPORTANT:** Replace these with actual sound effects!

The soundManager will load these files, but they are silent placeholders.
You need to add real MP3 sound files with the same names to hear audio in the game.

## Where to find sounds:
- Freesound.org
- Zapsplat.com  
- Mixkit.co
- Generate with SFXR/Bfxr

Keep files small (<100KB) and in MP3 format.
